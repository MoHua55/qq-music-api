# Security policy

## Supported versions

Security fixes are applied to the current `main` branch and released in the latest npm version after maintainer approval. Older versions may not receive fixes. See the [compatibility policy](./docs/compatibility.md) for upgrade steps.

## Reporting a vulnerability

Use a [private GitHub security advisory](https://github.com/yakult-green-tea/qq-music-api/security/advisories/new) for vulnerabilities, credential exposure, or authentication/session handling issues. Do not open a public issue containing sensitive details.

Include the package version, host environment, affected route or export, and the smallest reproducible sequence. Use synthetic values. Never include real QQ cookies, musickey values, QR keys, session tokens, account or device identifiers, auth-state files, `.env` contents, complete playback or authenticated URLs, or HAR files containing credentials.

This is an unofficial project. It is not affiliated with or authorized by Tencent or QQ Music.
